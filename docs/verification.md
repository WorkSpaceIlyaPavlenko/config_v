# Проверка первой серверной версии

Проверено 12 сентября 2026 года на Mac arm64, в отдельной Colima VM `config-v` (VZ, 2 CPU, 2 ГБ RAM).

- `npm run check`: 18 тестов, включая соответствие ключей, отсутствие секретов в Terraform-параметрах, сохранение активной конфигурации при ошибке нативного парсера, сверку байтов томов и проверку сохранённого плана.
- Terraform 1.16.2, Docker provider 4.6.0: `fmt`, `validate`, реальный `plan/apply` восьми ресурсов. Повторный план — **No changes**.
- Нативные Xray и Caddy приняли сгенерированные конфигурации.
- Обычный HTTPS на локальном порту Xray вернул тестовую страницу Caddy.
- Xray-клиент с правильными параметрами REALITY/Vision выполнил HTTPS-запрос к example.com с обычной проверкой сертификата.
- Неизвестный UUID не пропустил запрос; повторный запрос исправного клиента к тому же адресу прошёл.
- Контейнеры работают как UID 65532:65532, с read-only корнем, `cap_drop=ALL`, без host bind mounts. Публикуются только 127.0.0.1:8443 и 127.0.0.1:8080. Хранилища Caddy принадлежат UID 65532 и имеют режим 0700.
- В фактическом профиле Colima подтверждены `mounts: null`, `forwardAgent: false`, `autoActivate: false`, `sshConfig: false`.

Проверка подтверждает локальную работоспособность протокола и развёртывания. Публичный сертификат собственного домена, DNS, запуск на VPS и доступность из сетей России ещё не проверены. Эти шаги требуют настоящего домена и выбранной среды исполнения на сервере.

## Проверка единого запуска, 13 сентября 2026

- 40 Node-тестов: параметры, сохранение ключей, порядок init, отказ при ошибках, выбор контейнеров restart, проверка принадлежности, конфликт операций, семантический разбор YAML Colima.
- Полный `init` на временном `lifecycle-check` в Colima: seed, Terraform plan/apply 8 ресурсов, status и настоящий smoke-тест HTTPS/REALITY/Vision.
- Резолверы `1.1.1.1` и `9.9.9.9` дошли до фактических настроек обоих контейнеров.
- Повторный init: `No changes`; ключи и соединение сохранились.
- `restart:vpn`, `restart:client`, `restart:all`: по Docker StartedAt проверено, что перезапускаются только выбранные сервисы; ID контейнеров и ключи сохранены.
- `restart:back` сообщает об отсутствии будущего API-сервиса.
- После всех перезапусков снова проверены обычный HTTPS, рабочий REALITY/Vision-туннель и отказ неизвестному UUID.
- Временные контейнеры, четыре тома и сеть `lifecycle-check` удалены после сверки их принадлежности тестовому узлу; Colima остановлена.

Эти проверки не являются развёртыванием на production VPS или проверкой доступности из России.
